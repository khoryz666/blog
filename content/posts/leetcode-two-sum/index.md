## Question

You are given an array of integers `nums` and an integer `target`, return _indices of the two numbers such that they add up to `target`_.

You may assume that each input would have **_exactly_ one solution**, and you may not use the _same_ element twice.

You can return the answer in any order.

**Example 1:**

**Input:** `nums = [2,7,11,15], target = 9`

**Output:** `[0,1]`

**Explanation:**

The sum of `nums[0]` and `nums[1]` is `2 + 7 = 9`, which equals the target. Therefore, the indices `[0, 1]` are returned.

**Example 2:**

**Input:** `nums = [3,2,4], target = 6`

**Output:** `[1,2]`

**Explanation:**

The sum of `nums[1]` and `nums[2]` is `2 + 4 = 6`, which equals the target. Therefore, the indices `[1, 2]` are returned.

## My Implementation

My intuition is brute force, which is to loop through elements in `nums`, for each element `e = nums[i]`, find the subsequent element so that `target == e + nums[j]`. The python code is as follows:

```python
nums = [2,7,11,15]
target = 9
class Solution(object):
    def twoSum(self, nums, target):
        for i in range (len(nums)):
            e = nums[i]
            for j in range (i+1,len(nums)):
                if (e + nums[j] == target): 
                    return([i, j])
                    
# The following is generated by https://duck.ai
solution = Solution()
result = solution.twoSum(nums, target)
print(result)
```

struct Solution;

impl Solution {
	pub fn two_sum(nums: Vec<i32>, target: i32) -> Vec<i32> {
		for (i, &num) in nums.iter().enumerate() {
			for (j, &next_num) in nums.iter().enumerate().skip(i+1) {
				if num + next_num == target {
					return Vec::<i32>::from([i as i32, j as i32]);
				}
			}
		}
		vec![]
	}
}
// nums.iter() creates iterator that borrows elements of `nums`
// .enumerate() is an iterator method, it adds index and creates a tuple where (index, &num)
// .skip(i+1) skips first i+1 items, the +1 is because index starts from 0
fn main(){
	let nums = vec![2,7,11,15];
	let target = 9;
	
	let result = Solution::two_sum(nums, target);
	println!("{:?}", result);
}
